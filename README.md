# 🦉 Логічні ігри для дітей

Колекція логічних ігор українською для дітей 4–10 років — і для батьків, які грають разом із ними.
Без реклами, без реєстрації, працює в браузері на телефоні, планшеті й комп’ютері.

Це нова версія проєкту [logic_games](https://github.com/Damidola/logic_games) — старий репозиторій лишається як пам’ять.

## Ігри

| | Гра | Вік | Що розвиває |
|---|---|---|---|

| 🦊 | **Звірячі судоку** — поле 4×4, 6×6 або 9×9, 5 рівнів | 5+ | логіка, увага |
| ❌ | **Хрестики-нулики** — нова партія починається сама | 4+ | планування |
| 🔴 | **Чотири в ряд** — кидай фішки, збери четвірку | 5+ | просторове мислення |
| 🦎 | **Переправа** — саламандра проти риб | 6+ | стратегія |
| 👣 | **Сліди** — тури лишають сліди | 7+ | рахунок ходів |
| ♟️ | **Пішаки** — пішакова битва | 6+ | шахові основи |
| ⚫ | **Шашки** — російські шашки | 6+ | комбінації |
| 🔺 | **Кути** — переведи шашки в чужий кут | 7+ | планування маршруту |
| 🐴 | **Фігури й пішаки** — кінь, слон чи ферзь проти пішаків | 7+ | ходи фігур |

## Що однакове в усіх іграх

- **Верхня панель:** ⚙️ налаштування · ❓ правила · назва · 🏠 додому.
- **Кнопки внизу:** Колір · Заново · 💡 Підказка · ↩️ Назад · ↪️ Вперед.
- **5 рівнів робота:** 1 — піддається (робить найгірший хід, віддає фігури), 2 — слабкий, 3 — новачок, 4 — бадьорий, 5 — сильний, але його можна перемогти.
- **Тваринка-суперник** зі своїм фоном (рівень = тваринка); у налаштуваннях її можна вимкнути.
- **Спільні налаштування:** звук, тема, колір дошки, набір фігур, кількість підказок і ходів назад (за замовчуванням по 3).
- **Перемога** — смішне відео, «ще раз» і 🏠. У хрестиках-нуликах вікно зникає саме через 2 с.

## Як це влаштовано

Дошка 8×8 — [chessground](https://github.com/lichess-org/chessground) (дошка Lichess: перетягування, анімації, стрілки),
шахові правила — [chessops](https://github.com/niklasf/chessops). Обидві бібліотеки один раз зібрані в `shared/vendor/`,
тож сайт не потребує збирання.

```
index.html            головна сторінка
shared/games.js       каталог ігор: назви, правила, поради для батьків
shared/kit.js/.css    панель, вікна, звуки, налаштування, екран результату (window.LG)
shared/game.js        каркас партії: хід гравця → хід робота, назад/вперед, підказки, налаштування
shared/board.js       обгортка chessground, теми дошки, набори фігур
shared/ai.js          5 рівнів робота для будь-якої гри (мінімакс з альфа-бета)
shared/opponent.js    тваринки-суперники й фони
shared/play.css       вигляд сторінки гри
<гра>/rules.js        правила гри — усе, що є в кожній грі
learn/                уроки Lichess Learn (джерело в learn/src, збирається `npm run build` у learn/app.js)
```

### Як додати гру

1. Напишіть `<гра>/rules.js` з функцією `createRules()`, що повертає:
   `initial()`, `turn(s)` → `'w' | 'b'`, `moves(s)` (ходи `{ from: 'e2', to: 'e4', ... }`), `play(s, m)` → новий стан,
   `result(s)` → `null` або `{ winner: 'w' | 'b' | 'draw', text }`, `evaluate(s, side)`, `key(s)` і `pieces(s)` (Map клітинка → `{ role, color }`).
   Необов’язково: `captured`, `check`, `marks`, `midTurn`, `moveOrder`, `aiDepth`.
   Для поля не 8×8 передайте ще свій `view` (див. `ttt/view.js`).
2. Скопіюйте `index.html` будь-якої гри й викличте `startGame({ rules: createRules() })`.
3. Додайте запис у `shared/games.js`.

## Запуск локально

Жодних збірок не потрібно:

```bash
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

Сайт публікується на GitHub Pages автоматично при пуші в `main` (`.github/workflows/pages.yml`).

## Ідеї на майбутнє

Шахові задачі (каркас уже готовий: позиція FEN + відповідь, як у Lichess), турецькі шашки, доміно, рендзю, «Мисливці й вовк», дорога, Ханойські башти, нім.
