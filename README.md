# 🦉 Логічні ігри для дітей

Колекція логічних ігор українською для дітей 4–10 років — і для батьків, які грають разом із ними.
Без реклами, без реєстрації, працює в браузері на телефоні, планшеті й комп’ютері.

Це нова версія проєкту [logic_games](https://github.com/Damidola/logic_games) — старий репозиторій лишається як пам’ять.

## Ігри

| | Гра | Вік | Що розвиває |
|---|---|---|---|
| 🦊 | **Звірячі судоку** *(нова)* — поле 4×4, 6×6 або 9×9 зі звірятами | 5+ | логіка, увага |
| ❌ | **Хрестики-нулики** — три рівні робота | 4+ | планування |
| 🔴 | **Чотири в ряд** — кидай фішки, збери четвірку | 5+ | просторове мислення |
| 🦎 | **Переправа** — саламандра проти риб | 6+ | стратегія |
| 👣 | **Сліди** — тури лишають сліди | 7+ | рахунок ходів |
| ♟️ | **Пішаки** — пішакова битва з 7 суперниками-звірятами | 6+ | шахові основи |
| ⚫ | **Шашки** — класика проти робота | 6+ | комбінації |
| 🔺 | **Кути** — переведи шашки в чужий кут | 7+ | планування маршруту |
| 🐴 | **Фігури й пішаки** — кінь, слон чи ферзь проти пішаків | 7+ | ходи фігур |
| 🔷 | **Чешки** — шахи з кружечками, трикутниками й квадратами | 8+ | гнучкість мислення |
| ♞ | **Шахи** — два рівні робота, скасування ходу | 7+ | стратегія |

## Що нового порівняно зі старою версією

- **Єдиний світлий дизайн** для всіх ігор: великі кнопки, округлий шрифт, яскраві кольори.
- **Верхня панель у кожній грі**: 🏠 додому, ❓ правила, 🔊 звук.
- **Правила простими словами** + розділ «Для батьків» — відкриваються самі при першому запуску гри.
- **Святкування перемоги**: конфеті, звук, похвала; після поразки — підбадьорення замість «Ти програв :(».
- **Зірочки**: кількість перемог у кожній грі видно на головній.
- **Для батьків** на головній: час гри сьогодні й за тиждень, нагадування про перерву, що розвиває кожна гра, з чого почати за віком.
- Системні `alert` замінено на дружні підказки.
- Ігри **підлаштовуються під екран** телефона (раніше деякі дошки мали фіксовану ширину й вилазили за край).
- Шахи й «Фігури й пішаки» перекладено українською; у шахах з’явилися «Нова гра», «Назад» і хитріший робот.
- У «Кутах» — кнопка «✅ Завершити хід» після стрибків і позначки будиночка 🏁.
- У «Чотири в ряд» підсвічується переможна четвірка.

## Структура

```
index.html          головна сторінка
shared/games.js     каталог ігор: назви, правила, поради для батьків
shared/kit.js       спільна панель, правила, звуки, конфеті, статистика (window.LG)
shared/kit.css      кольори, шрифт, кнопки, вікна
<гра>/              кожна гра у своїй папці
puzzles/            інструмент для тренера: PGN → PDF із задачами
```

Щоб підключити нову гру: додайте запис у `shared/games.js`, а в HTML гри —

```html
<link rel="stylesheet" href="../shared/kit.css">
<script src="../shared/games.js"></script>
<script src="../shared/kit.js" data-game="my-game"></script>
```

і викликайте `LG.win(текст, { onAgain })`, `LG.lose(...)` або `LG.draw(...)` наприкінці партії.

## Запуск локально

Жодних збірок не потрібно:

```bash
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

Сайт публікується на GitHub Pages автоматично при пуші в `main` (`.github/workflows/pages.yml`).
