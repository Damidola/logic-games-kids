# Логічні ігри як Telegram Mini App

Mini App — це звичайний сайт, який Telegram відкриває у своєму вікні. Сайт уже
публікується на GitHub Pages (`.github/workflows/pages.yml`, з гілки `main`):

**https://damidola.github.io/logic-games-kids/**

Код під Telegram уже є в `shared/kit.js`, його підключає кожна сторінка. У звичайному браузері він нічого не робить.

- Скрипт Telegram (`telegram-web-app.js`) завантажується тільки тоді, коли сайт відкрито всередині Telegram.
- Застосунок розгортається на весь екран (`expand`).
- **Свайп вниз не закриває застосунок** (`disableVerticalSwipes`). Без цього дитина, тягнучи фігуру чи фішку вниз, випадково закривала б гру.
- Колір шапки Telegram збігається з фоном сторінки, зокрема в нічній темі.
- На сторінці гри системна кнопка «Назад» Telegram працює як 🏠: повертає до списку ігор.

## Крок 1. Опублікувати сайт

1. Злийте зміни в `main` (наприклад, через pull request). Workflow **Deploy to GitHub Pages** сам викладе сайт.
2. Якщо Pages ще не ввімкнено: GitHub → репозиторій → **Settings → Pages → Source: GitHub Actions**.
3. Перевірте, що https://damidola.github.io/logic-games-kids/ відкривається в браузері телефона.

## Крок 2. Створити бота

1. У Telegram відкрийте **@BotFather** → `/newbot`.
2. Введіть назву (наприклад, `Логічні ігри`) та ім'я, що закінчується на `bot` (наприклад, `logic_games_kids_bot`).
3. BotFather дасть токен. Для Mini App він не потрібен, тож його нікому не показуйте й нікуди не вставляйте.

## Крок 3. Кнопка «Грати» в чаті з ботом

1. @BotFather → `/mybots` → ваш бот → **Bot Settings → Menu Button → Configure menu button**.
2. Надішліть URL: `https://damidola.github.io/logic-games-kids/`
3. Надішліть підпис кнопки: `🎮 Грати`

Тепер у чаті з ботом, ліворуч від поля введення, з'явиться кнопка, яка відкриває ігри.

## Крок 4 (за бажанням). Пряме посилання t.me/…

1. @BotFather → `/newapp` → виберіть бота.
2. Введіть назву, опис і картинку 640×360. Картинку можна пропустити командою `/empty`.
3. URL: `https://damidola.github.io/logic-games-kids/`
4. Коротке ім'я, наприклад `games`.

Посилання буде `https://t.me/<ім'я_бота>/games`. Ним можна ділитися в чатах, і воно відкриває гру одразу.

Режим **Fullscreen** у налаштуваннях Mini App не вмикайте: тоді кнопки Telegram накриють верхню панель гри (🏠 ❓ ⚙️). Підходить звичайний режим, у якому застосунок розгорнутий на весь екран.

## Оновлення

Після кожного злиття в `main` сайт оновлюється сам, а в BotFather нічого міняти не треба.
Telegram кешує сторінки, тому після змін збільшуйте число `?v=…` у підключеннях `shared/*.css|js` в усіх `*.html`. Якщо старе не зникає, закрийте й знову відкрийте застосунок.

## Перевірка

- Відкрийте бота на телефоні → **🎮 Грати** → виберіть гру.
- Потягніть фігуру вниз: застосунок не має закритися.
- Натисніть «Назад» у шапці Telegram: має відкритися список ігор.
- Прогрес і налаштування зберігаються окремо від браузера телефона (у Telegram своє сховище).
